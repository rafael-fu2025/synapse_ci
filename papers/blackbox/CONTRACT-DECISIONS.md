## Decision recording rule

To close an entry, the named owner(s) must record:

1. approved decision and effective date;
2. exact role/field/state/route/flag semantics;
3. source/config/migration/UI changes required (or “documentation only” with rationale);
4. backward-compatibility and data migration impact;
5. cases to update and the commit that implements the decision.

Change `OPEN` only to `DECIDED` when that record exists and affected cases no longer ask the tester to choose an interpretation. A run cannot close a policy question merely by observing whichever branch happened to be configured.
