# Black Box Testing
Black Box Testing was conducted to evaluate SYNAPSE's functional correctness based on user inputs and expected outputs, without examining the internal code or implementation. The testing focused on verifying that the platform's modules behave as expected when students, employees, clinic staff, guidance counsellors, facilities staff, and administrators interact with the system's features across its four portal surfaces and the mobile application, including authentication, appointments, queueing, clinical encounters, counselling cases, referrals, composting operations, real-time updates, governed AI insights, and system administration. The Actual Output and Result columns are populated at the time of test execution.

## Execution progress (live tracker)

This file is the authoritative tracker for the complete SYNAPSE black-box suite. **PASS** = executed and the expected behaviour was observed · **FAIL** = executed and the observed behaviour contradicted the expectation · **BLOCKED** = the case could not be executed in this environment (the blocking reason is in the Remarks column). A completed case must **not** be re-run; the full evidence lives in the per-module result files listed at the bottom of this file.
